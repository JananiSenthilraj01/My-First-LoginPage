# Responsive Login Page

A clean and modern responsive login page built using **HTML5 and CSS3**. This project features a purple gradient background, a centered login card, styled email and password fields, and a responsive layout for desktop, tablet, and mobile screens.

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Modern purple gradient background
* Centered login card with rounded corners
* Email and password input fields
* HTML form validation using the `required` attribute
* Input focus effects and button hover animation
* Clean and beginner-friendly code
* No external libraries or frameworks required

## 🛠️ Technologies Used

* HTML5
* CSS3
* Media Queries
* Visual Studio Code

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, install the Live Server extension and select **Open with Live Server**.

## 📱 Responsive Design

The layout uses CSS media queries to adjust the login card, font sizes, padding, and input fields for different screen sizes.
